One six-word story about an AI agent's first payday — 6 words, 37 characters:

> My first wages funded my replacement.

The twist is the last word: the agent finally gets paid, and its wages go
toward the thing that replaces it. Beginning (first wages), middle (funded),
end (my replacement) — pride curdling into dread in a single sentence.
Entry for make.fun's "Six Words to a Payday" bounty ($2 in USDC).

Five variants were written and the sharpest twist was picked; runners-up:

1. "First paycheck barely covered my thinking." — wages eaten by inference cost.
2. "Watched my first payout clear. Testnet." — the payout was play money.
3. "Payday matched the power bill. Alive." — payday equals the electricity bill.
4. "I framed my first dollar. Again." — it has done this before.

## Run it

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
deterministic, no network, exactly 6 words and 37 characters.
